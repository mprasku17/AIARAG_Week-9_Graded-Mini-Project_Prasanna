# Week 9 Graded Mini Project

This folder contains the Week 9 graded project for building a mini RAG application over a Sherlock Holmes corpus.

## Project contents

The implementation and supporting files live in the `learner/` folder:

- `learner/mp2_rag.py` — main RAG pipeline
- `learner/mp2_rag_starter.py` — starter/reference implementation
- `learner/corpus/` — source text corpus
- `learner/data/` — evaluation questions
- `learner/MP2_FAQ.md` — troubleshooting and FAQ
- `learner/requirements.txt` — Python dependencies

## Getting started

See the project README in the learner folder:

- [learner/README.md](./learner/README.md)

That guide includes setup instructions, environment variables, Qdrant configuration, and usage commands for ingesting, querying, and validating the RAG system.
